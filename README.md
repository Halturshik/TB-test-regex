# Демонстрационный код для проверки гипотезы изменения правила маршрутизации на исторических чатах

Пример запуска:
```bash
go run routing_rule_check.go -input lifestyle_eval.csv -split test
```

Параметр -split поддерживает значения:
- all — вся выборка;
- train — 80% выборки;
- test — 20% отложенной выборки.
